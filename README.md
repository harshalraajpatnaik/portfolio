## 🌿 SthiraX: The Business × Technology Capstone

**Topic:** *Distributed CO₂-Mineralization Platform for Certified Low-Carbon Precast Materials in India*  
**Institution:** Indian Institute of Management Kozhikode (IIMK) — Executive PGPM Capstone (BPP)

```
       [ Regional Steel Slag & CO₂ Source ]       [ Small/Scattered Precast Plants ]

               +----------------------------------------------------+
               |              DISTRIBUTED MRV SOFTWARE              |
               |  IoT Batch Curing Logs · Calcium Carbonate Uptake   |
               |  Tamper-Evident Digital Product Passports (DPP)     |
               +-------------------------+--------------------------+
                                         |
                                         v
               [ EPC Contractors & Real Estate Developers (EPR Mandate) ]
```

### The Strategic Pillars
1. **Regulatory Tailwind (Market Creation by Law)**: On 1 April 2026, India's MoEF&CC C&D Waste Management Rules took force. All construction projects >20,000 sqm must recycle debris, climbing to 100% by 2028–29, with new buildings requiring 5% to 25% recycled material by 2030. India currently recycles <1% of its 100M annual tonnes.
2. **Asset-Light Platform Design**: Rather than building capital-intensive manufacturing plants, SthiraX retrofits thousands of small, scattered precast plants into a unified certified low-carbon supply network.
3. **Distributed IoT MRV Software**: Proprietary batch-level Measurement, Reporting & Verification (MRV) IoT software tracks calcium carbonate uptake per production run and generates tamper-evident Digital Product Passports for developer EPR compliance.
4. **Resilient Unit Economics**: Multi-tier monetization (retrofit onboarding fees, equipment leasing, per-tonne curing royalty, and MRV SaaS subscriptions) viable independent of voluntary carbon credit market volatility.

## 📄 1-Page Google ATS Resume Engine

The resume engine produces a clean, machine-parsable 1-page document formatted strictly to Google and tier-1 ATS recruitment standards.

- **Google X-Y-Z Metric Alignment**: Formatted using the standard *"Accomplished [X] relative to [Y] by doing [Z]"*.
- **Strict 1-Page Geometry**: Tuned print margins (-0.65in, 0.42in top/bottom) validated by system metadata (`kMDItemNumberOfPages = 1`).
- **Real-Time Delivery Endpoints**:
  - `GET /api/v1/resume/download` — Direct 1-page vector PDF download (`Content-Disposition: attachment`).
  - `GET /api/v1/resume/latex` — Raw `.tex` LaTeX source code download.

## 🚀 Local Development & Quick Start

### Prerequisites
- **Java 17 LTS** (OpenJDK / Corretto)
- **Node.js 20 LTS** & **npm 10+** (Recommended via `nvm`)
- **Maven 3.9+** (or bundled `mvnw`)
- **Google Chrome** (for headless PDF generation)

### 1. Clone the Repository
```bash
git clone https://github.com/harshalraajpatnaik/portfolio.git
cd portfolio
```

### 2. Run the Spring Boot Backend
```bash
cd backend
mvn clean package -DskipTests
java -jar target/portfolio-backend-1.0.0.jar
```
*Backend runs on `http://localhost:8080`.*

### 3. Run the Angular Frontend
```bash
cd ../frontend
npm install
npm start
```
*Frontend runs on `http://localhost:4200`.*
